# Intelligent Vendor Performance and Delivery Risk Management System

## Overview
An AI-powered system that evaluates vendor performance, predicts delivery risks, tracks purchase orders, and helps businesses make better vendor management decisions.

 Features
- Vendor profile management
- Purchase order tracking
- ML-based delivery risk prediction (Low, Medium, High)
- Risk probability and contributing factors
- Delivery risk alerts
- Vendor performance scoring and comparison
- Quality evaluation and delivery tracking
- Historical performance analysis

Tech Stack
- Frontend: HTML, CSS, JavaScript, Chart.js
- Backend: Java, Spring Boot
- Database: MySQL
- Machine Learning API:Python, FastAPI
- ML Model:Random Forest

 Project Structure
- `frontend/` — User interface
- `backend/` — Spring Boot REST API
- `ml/` — Machine learning model, dataset, and prediction API

Getting Started
1. Configure the database credentials using your local environment variables.
2. Start the Spring Boot backend.
3. Start the Python ML API.
4. Run the frontend using a local development server.

 Purpose
The system combines vendor performance analytics and machine learning to identify potential delivery delays and support proactive decision-making.

 Status
Developed as an academic project.
